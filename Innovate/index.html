How the score is explained

The baseline combines change category, change size, environment, and recorded rollback history. The factors are visible so a reviewer can challenge the reasoning.

Human-in-the-loop safeguard

High-risk deployments should require human review. This prototype does not execute real infrastructure changes.

  • Build labeled incident history.
  • Evaluate model precision and false positives.
